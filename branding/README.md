# FernOS branding

Slogan: **"A calmer way to use the internet."**

| Role | Color | Source |
|---|---|---|
| Forest (dark background) | `#18271F` | Fern `theme.py` background |
| Surface dark | `#26382D` | Fern surface |
| Moss | `#82966B` | Fern moss |
| Moss light | `#9BAE7D` | Fern moss_light |
| Leaf (light accent) | `#597B55` | Fernblox light accent |
| Cream (text on dark) | `#EDE8D8` | Fern text |
| Paper (light background) | `#F3F0E5` | Fernblox light background |
| Walnut | `#B99A72` | Fern walnut |

* `logo/fern-original.png`: original Fern app icon (100×100), kept for reference.
* `logo/fernos.svg`, `logo/fernos-badge.svg`: vector FernOS logo generated by `tools/make_logo.py`.
* `wallpaper/*.svg`: wallpaper sources generated by `tools/make_wallpaper.py`.
* `dist/`: rendered PNGs, regenerated with `tools/render-assets.sh`.

Style: natural, minimal, calm. Flat shapes, no glow, gradients only for soft skies.
